A project settings file can set any setting, including base_url, https_proxy and repository. snouty sends your API key to base_url, sends its requests through https_proxy, and pushes your images to repository, so a settings file from a cloned repository could send your credentials or images to another server. Read the file, or run `{{ t("snouty --settings ./.snouty.toml settings show")? }}` to see the settings that snouty would resolve with it, before you trust it. If you do not want snouty to use the file, run `{{ t("snouty settings deny")? }}`.
