Cancel a run that is starting or in progress.

Cancellation is asynchronous. When the command succeeds, the server has marked the run as cancelled, but it can still be stopping. A run that has already completed or is incomplete cannot be cancelled: the command fails and the run does not change.

The command needs tenant release 63.0 or newer; `{{ t("snouty doctor")? }}` reports the tenant release.

Examples:
  {{ t("snouty runs cancel <run_id>")? }}
