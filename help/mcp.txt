Serve snouty's run, docs, doctor and settings commands to AI agents over MCP

This command is gated behind the `mcp` unstable feature, because its tools and their output can still change. Enable it by setting SNOUTY_UNSTABLE_FEATURES=mcp. An unstable feature can change or go away in any release.

Starts a Model Context Protocol server on stdin and stdout. An agent starts `snouty mcp` itself and talks to it over the stdio transport. The server stops when stdin closes, and the tool calls in progress stop with it.

The tools:
{{ tool_table() }}

Each tool runs its snouty command and returns what the command prints: stdout, then stderr in a second block when there is any. The output is the text output of the command, in its detailed form. When a tool's `json` param is true, the output is the command's JSON output. The params of a tool are the other arguments of its command, by name. A command that fails marks the result isError.

A tool call has no time limit and no output limit, and the result arrives only when the command ends. A call that waits until a run is ready, or that rewarms a moment, can take minutes. A long call sends progress, so a client that resets its time limit on progress does not end it. When the client cancels a call, its command stops. Up to {{ t("--max-concurrent-calls")? }} tool calls run at the same time.

{{ t("--settings")? }}, {{ t("--profile")? }} and {{ t("--verbose")? }}, and the ANTITHESIS_* environment variables, apply to every tool call as they do for the other commands.

Example, to add snouty to Claude Code:
  claude mcp add snouty -e SNOUTY_UNSTABLE_FEATURES=mcp -- snouty mcp
