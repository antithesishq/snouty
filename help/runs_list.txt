List recent runs{% if cli %} (the default when `snouty runs` runs with no subcommand){% endif %}.

{% if cli %}
Columns: RUN ID, STATUS, CREATED, TEST NAME. Use --detail for the full
description and launcher.

Add --json for machine-readable output. Each run prints as one JSON object on
its own line, in the order the server returns them:
  snouty --json runs list | jq -r .run_id
{% else %}
status, launcher, created_after and created_before filter the runs on the
server. limit sets the maximum number of runs to return (default 10).

Returns one JSON object per run, one per line, in the order the server
returns them. The keys include run_id, status, created_at, launcher and
description. Pass run_id to the other runs tools.
{% endif %}
