Show a run's metadata: id, status, timestamps, launcher, and description.

Created, Started and Completed are in the local timezone.

Elapsed is wall-clock time spanning provisioning, setup, fuzzing, and teardown. Creator is the name of who launched the run (a user, a CI job or an agent). The run also has its user-defined attributes ({% if cli %}`--param attrs.<name>=<value>`{% else %}`attrs.<name>` params{% endif %} at launch) under Attributes.

An incomplete run also has its failure moment (Failure Hash/VTime), to pass to `{{ t("runs logs")? }}`, and a failure reason when the run reports one.{% if cli %} Use --web to open the run's page in a browser.{% endif %}

Examples:
  {{ t("snouty runs show <run_id>")? }}
{%- if cli %}
  {{ t("snouty runs show <run_id> --web")? }}
{%- endif %}

With {{ t("--json")? }}, the run prints as one JSON object, with its times in RFC 3339 in UTC.{% if cli %} With {{ t("--web")? }}, it prints the run page URL as {"url": ...} and opens no browser.{% endif %}
