Wait until a run is ready or complete.

{{ t("--until")? }} sets the status to wait for:
  ready     The run is ready to use, or it is already complete.
  complete  The run is complete: completed, cancelled, or incomplete. This
            is the default.

The status is a minimum. A run can only move forward, and a complete run never starts again. Thus {% if cli %}`--until ready`{% else %}a wait until ready{% endif %} on a complete run returns at once.

When the run reaches the status, the command prints the run's current status and exits 0, whatever that status is. A run that reports status `unknown` fails the command: snouty cannot tell whether such a run will still make progress.

The wait is unbounded unless {{ t("--timeout")? }} is given. The command is safe to interrupt and re-run: it holds no state beyond the run id.

Examples:
  {{ t("snouty runs wait <run_id>")? }}
  {{ t("snouty runs wait <run_id> --timeout 2h")? }}
  {{ t("snouty runs wait <run_id> --until ready")? }}
{%- if cli %}
  snouty launch --json --config ./config ... | jq -r .runId | xargs snouty runs wait
{%- endif %}
