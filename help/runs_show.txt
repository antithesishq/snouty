Show a run's metadata: id, status, timestamps, launcher, and description.

Created, Started and Completed are in the local timezone.

Max Compute Hours and Setup Timeout are the values that the launch requested, when the run has them. One compute hour is one core running for one hour. Elapsed is wall-clock time, which also spans provisioning, setup and teardown. Source is the `antithesis.source` the run was launched from, when the launcher recorded one. The run also has its user-defined attributes ({% if cli %}`--param attrs.<name>=<value>`{% else %}`attrs.<name>` params{% endif %} at launch) and the `vcs.*` parameters that the Antithesis GitHub trigger action records (repository, branch, and commit), under Attributes and Version Control.

An incomplete run also has its failure moment (Failure Hash/VTime), to pass to `{{ t("runs logs")? }}`, and a failure reason when the run reports one.{% if cli %} Use --web to open the run's page in a browser.{% endif %}

Examples:
  {{ t("snouty runs show <run_id>")? }}
{%- if cli %}
  {{ t("snouty runs show <run_id> --web")? }}
{%- endif %}

{% if cli %}
Add --json for machine-readable output. The run prints as one JSON object, with its times in RFC 3339 with the local UTC offset. With --web it prints the run page URL as {"url": ...} and opens no browser:
  {{ t("snouty --json runs show <run_id> | jq -r .status")? }}

With {{ t("--json")? }}, the run prints as one JSON object, with its times in RFC 3339 with the local UTC offset.
