List a run's property (assertion) results, one table per group.

Each table is headed by its group; columns are STATUS, ✓, ✗, ID, NAME (failing first). STATUS is pass, fail, or unseen. An unseen property is undetermined: it has not triggered yet, and {{ t("--undetermined")? }} selects it. ✓ is the example count and ✗ is the counterexample count; large counts are shortened, as in 186k. ID is the property ID, for `snouty runs property`.

Filter by status with {{ t("--passing")? }}, {{ t("--failing")? }}, and {{ t("--undetermined")? }}. Give more than one to show each of those statuses.

Narrow with {{ t("--name")? }} and/or {{ t("--group")? }}. Both are case-insensitive substring matches against the relevant fields.{% if cli %} Add --detail to expand the matches into their examples and counter-example moments instead of the table.{% endif %} To show one property by its ID, use `snouty runs property <run_id> <property_id>`.

Examples:
  {{ t("snouty runs properties <run_id> --failing")? }}
  {{ t("snouty runs properties <run_id> --failing --undetermined")? }}
{%- if cli %}
  {{ t("snouty runs properties <run_id> --name eventually_validate --detail")? }}
  {{ t("snouty runs properties <run_id> --group Unreachable --detail")? }}
{%- endif %}
