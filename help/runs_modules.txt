List the instrumented modules that a run loaded. Use it to check that the run instrumented each component that you expect. Runs created before release 64 have no module list.

{% if cli %}
Each row is one module: MODULE, NAME, LANG, LOCATIONS and SYMBOLS. With {{ t("--detail")? }}, each row is one module in one program, with CONTAINER and PROGRAM after NAME, and a module whose programs are not listed yet has a blank CONTAINER and PROGRAM.
{% else %}
Each row is one module in one program: MODULE, NAME, CONTAINER, PROGRAM, LANG, LOCATIONS and SYMBOLS. A module whose programs are not listed yet has a blank CONTAINER and PROGRAM.
{% endif %}

MODULE is the module ID. LOCATIONS is the number of instrumented locations in the module, not a count of the locations that the run reached. SYMBOLS is `no` when Antithesis does not have the module's symbols, usually because the binary was not in `/symbols`. The coverage of such a module still counts, but the run has no file or function for its locations, and LANG is blank.

{% if cli %}
On a terminal, a long NAME or PROGRAM that contains a `/` is shortened at the start, and any other long NAME or CONTAINER at the end. Off a terminal, nothing is shortened. The rows are sorted by module, then container. After the table, a status line on stderr counts the modules, and gives the run's status.
{% else %}
The rows are sorted by module, then container. A status line under the table counts the modules, and gives the run's status.
{% endif %}

A module appears only after a program loads it. So while the run is in progress, more modules can appear. A process that does not start, or that starts only on a rare path, does not load its modules. A module ID is dependable for a module that the build uploads, such as a Go package's ID from its table in `/symbols`, or a native binary's GNU build ID. Antithesis assigns the IDs of other modules, such as Java, .NET and JavaScript modules.

With {{ t("--json")? }}, each module prints as one JSON object on its own line.{% if cli %} With {{ t("--detail")? }} too, the programs that loaded it are in `instances`.{% endif %}

Examples:
  {{ t("snouty runs modules <run_id>")? }}
{%- if cli %}
  {{ t("snouty runs modules <run_id> --detail")? }}
{%- endif %}
