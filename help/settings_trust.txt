Use a project settings file while its content stays the same

Records that you trust the settings file at {{ t("path")? }} with its current content. snouty then uses the file. When the content changes, snouty stops with an error until you trust the file again. Read the file before you trust it: it can set where snouty sends your credentials.

snouty keeps the record in trust.toml, in the global settings directory.

Examples:
  {{ t("snouty settings trust")? }}
  {{ t("snouty settings trust path/to/.snouty.toml")? }}
