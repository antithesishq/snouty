# snouty runs cancel
#
# Cancel a run that is starting or in progress (`POST
# /api/v0/runs/{run_id}/cancel`). Cancellation is asynchronous: success means
# the server marked the run as cancelled, but its jobs can still be stopping.
# Verified against the live API (orbitinghail, release 64.0):
#
#   - A starting run answers 200 `{}`, and `runs show` reports it cancelled
#     at once, with its completion time set.
#   - A cancel sent again over the next 8 minutes answers 200 `{}` and
#     changes nothing, although the spec documents 409 for a cancelled run.
#   - A completed run answers 409 with "Conflict: Run <id> has already
#     finished and cannot be cancelled", and keeps its status.
#   - An unknown run id answers a bare 404.
#
# The request is a POST, so a transport failure is never retried: the
# cancellation is sent exactly once.

# Like every runs command, cancel requires an API key.
! snouty runs cancel some-run
stderr 'No Antithesis credentials found.*'

# A run ID is required.
! snouty runs cancel
stderr '.*RUN_ID.*'

# `snouty runs --help` lists the cancel subcommand.
snouty runs --help
stdout 'cancel.*Cancel a run'

# `snouty runs cancel --help` explains that cancellation is asynchronous and
# that a completed run cannot be cancelled.
snouty runs cancel --help
stdout 'asynchronous'
stdout 'already completed'

# Every case below sends a cancel request, so none of them run against
# staging.
[staging] skip

# Cancelling a run in progress confirms the cancellation on stdout and notes
# on stderr that its jobs can take time to stop. run-2 is the mock's
# in-progress fixture.
mock-runs-server
snouty runs cancel run-2
stdout '^cancelled run run-2$'
stderr 'take some time to stop'

# `snouty --json runs cancel` prints the run id as one JSON object, and no
# note.
mock-runs-server
snouty --json runs cancel run-2
stdout '^\{"run_id":"run-2"\}$'
! stderr 'take some time'

# A run that has already completed cannot be cancelled. The command fails,
# says why, and points at `runs show` for the run's final status.
mock-runs-server
snouty --json runs list --status completed

! stderr '.*API error.*'
