Give Docker the credential for the tenant's container registry

A Docker credential helper for the tenant registry, registry.<tenant>.antithesis.com. Docker starts the helper itself, through the docker-credential-snouty binary that is installed next to snouty. To use it, add the registry to "credHelpers" in ~/.docker/config.json:

  {
    "credHelpers": {
      "registry.<tenant>.antithesis.com": "snouty"
    }
  }

Then `docker push` and `docker pull` sign in with your snouty credential, and `docker login` is not necessary.

get reads a server URL from stdin, and prints the credential for it as JSON. list prints a JSON object that maps each registry that snouty has a credential for to its username. Snouty owns the credential, so store and erase read stdin, change nothing, and succeed: `docker login` and `docker logout` do not fail. Run `snouty login` to change the credential.

The username is snouty-token. The password is your API key, or your OAuth access token from `snouty login`. Each get refreshes the OAuth token, so a long push has the full lifetime of the token.

Docker does not give the helper a profile, so get uses the profile whose settings agree with the requested host: its repository is on that host, and the host is registry.<tenant>.antithesis.com for its tenant. The selected profile (--profile or ANTITHESIS_PROFILE) wins when it agrees. Then the top-level defaults win. Then one named profile can agree; when more than one does, get fails, and you set ANTITHESIS_PROFILE to select one. Environment variables, such as ANTITHESIS_TENANT, ANTITHESIS_REPOSITORY and ANTITHESIS_API_KEY, apply to every profile. Docker starts the helper in its own working directory, so a ./.snouty.toml there is read too.

When no profile agrees with the host, get prints "credentials not found in native keychain" and exits with status 1, as Docker expects. Each other error goes to stdout as one line, where Docker shows it, and to stderr in full.

Examples:
  echo registry.acme.antithesis.com | snouty docker-credential get
  snouty docker-credential list
