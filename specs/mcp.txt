# snouty mcp
#
# An MCP server on the stdio transport. tests/mcp.rs drives the server with
# an MCP client, and covers what a tool call returns. This spec covers the
# command and the params of a tool.

# 1. At least one tool call must be able to run.
! snouty mcp --max-concurrent-calls 0
stderr 'invalid value .0. for .--max-concurrent-calls'

# 2. A client that closes stdin before it sends a request stops the server,
#    which exits 0.
stdin empty.txt
snouty mcp
! stdout .

# 3. A command that prints the same in both forms has no `json` param, and
#    `detail` is never a param. A bad param fails before any command runs.
#    `version` needs no API, and with `json` returns the version as JSON.
# Stdin closes as soon as the server reads calls.jsonl, and a call still
# running then can lose its response. So no call here may reach the API.
# The spec engine drops the final newline of a file, so the server never
# reads the last line of calls.jsonl, a ping.
stdin calls.jsonl
snouty mcp
stdout '"id":2,.*"text":"invalid params: unknown param: json"'
stdout '"id":3,.*"text":"invalid params: unknown param: detail"'
stdout '"id":4,"result":\{"content":\[\{"type":"text","text":"\{\\\\n +\\\\"version\\\\": \\\\"[0-9].*"isError":false'
