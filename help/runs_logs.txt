Stream the logs of one timeline of a run.

An Antithesis run is a tree of timelines. From one moment, Antithesis can send different inputs, and each input starts a new branch. An input_hash names the part of a branch from one input to the next. Each event has a moment: an input_hash, and a vtime, the virtual time on that branch.

{{ t("input_hash")? }} selects a path in the tree. The logs stream from the root, through each earlier input_hash on the path, to the end of {{ t("input_hash")? }}. {% if cli %}{{ t("input_hash")? }} is often negative, such as `-123`; pass it as it is, with no `--` before it. {% endif %}Give {{ t("vtime")? }} to end the stream at that moment, or {{ t("--begin-vtime")? }} to start it later than the root. A run in progress can extend {{ t("input_hash")? }}, so it can return more logs later. Find a moment with `{{ t("runs properties --detail")? }}`, `{{ t("runs events")? }}`, `{{ t("runs search")? }}`, or the failure moment of an incomplete run in `{{ t("runs show")? }}`.

Each event also has a source and a payload: log output, an SDK assertion, a fault, a container lifecycle change, or a test composer command.

{% if cli %}
Output: a `moment HASH` divider opens the events of each input_hash on the path, from the root to {{ t("input_hash")? }}. Each event under it renders on one line as `VTIME [source] payload`, each event shape in its own concise form. VTIME is truncated to fit its column, and a long source label ends in `…`. With {{ t("--detail")? }}, VTIME and the source print whole, and indented lines under an event give its source location, as `@ file:function:line`, and the details that it carries, such as an SDK assertion's details, as `details {...}`.
{% else %}
A `moment HASH` line opens the events of each input_hash on the path, from the root to {{ t("input_hash")? }}. Each event under it prints as one `VTIME [source] payload` line, with the full vtime. Indented lines under an event give its source location, as `@ file:function:line`, and the details that it carries, such as an SDK assertion's details, as `details {...}`.
{% endif %}
