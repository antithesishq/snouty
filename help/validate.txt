Validate local Antithesis setup

Compose configs:
Starts the compose config locally and waits for the setup-complete event. All images must be available locally.

Then validate checks that each test command in /opt/antithesis/test/v1 has a recognized prefix and is executable, and prints how many test commands of each type it found. Test commands are not executed.

Validate fails when docker-compose.yaml depends on your shell environment, such as a ${VAR} that resolves differently in the Antithesis environment. Use {{ t("--allow-compose-divergence")? }} to make that a warning.

If your container engine runs in a VM, set SNOUTY_TEMP_DIR to a directory that the VM shares with write access.

Kubernetes configs:
Checks the manifests in the manifests/ directory without starting anything. {{ t("--timeout")? }}, {{ t("--keep-running")? }} and {{ t("--allow-compose-divergence")? }} do not apply.

Examples:
  {{ t("snouty validate ./config")? }}
  {{ t("snouty validate ./config --timeout 5m")? }}
  {{ t("snouty validate ./k8s-config")? }}

Next, launch the config with `{{ t("snouty launch --config ./config")? }}`. A Kubernetes config needs the Kubernetes launcher: `{{ t("snouty launch --launcher basic_k8s_test --config ./k8s-config")? }}`.
