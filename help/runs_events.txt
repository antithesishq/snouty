Search a run's events for one or more substrings (all must match).

{% if cli %}A term, from {{ t("--match")? }} or {{ t("query")? }},{% else %}Each {{ t("--match")? }} value{% endif %} is matched against the text an event carries: log output, an assertion's message and source function, and a test-composer command.

Each matching event has its moment (an input_hash and a vtime), its source, and its payload: log output, an SDK assertion, a fault, a container lifecycle change, or a test composer command. To stream the logs of an event's timeline to its current end, pass its run ID and input_hash to `{{ t("snouty runs logs <run_id> <hash>")? }}`.

{% if cli %}
Output: a `moment HASH` divider opens each timeline segment, and each event under it renders on one line as `VTIME [source] payload`, each event shape in its own concise form. VTIME is truncated to fit its column, and a long source label ends in `…`. With {{ t("--detail")? }}, VTIME and the source print whole, and indented lines under an event give its source location, as `@ file:function:line`, and the details that it carries, such as an SDK assertion's details, as `details {...}`.
{% else %}
A `moment HASH` line opens each timeline segment, and each event under it prints as one `VTIME [source] payload` line, with the full vtime. Indented lines under an event give its source location, as `@ file:function:line`, and the details that it carries, such as an SDK assertion's details, as `details {...}`.
{% endif %}

Every term must match, case-insensitively. The result is a sample of the matching events in no fixed order, capped at {{ t("--limit")? }}. Read {% if cli %}`snouty runs search --help`{% else %}`tool_help {"tool": "runs_search"}`{% endif %} to learn how to read a sample and how the run's timelines relate the events.

The run must be ready or complete. If it is not, the command waits until it is ready, as `{{ t("snouty runs exec")? }}` does, and says that it waits.

{% if cli %}
To see the equivalent `snouty runs search` query, run `snouty --verbose runs events ...`.
{% endif %}

Examples:
  {{ t("snouty runs events <run_id> -m error")? }}
  {{ t("snouty runs events <run_id> -m error -m node-0 -n 100")? }}
