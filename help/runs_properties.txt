List a run's property (assertion) results, one table per group.

Each table is headed by its group; columns are STAT, ✓, ✗, ID, NAME (failing first). STAT is pass or fail, and is empty for an undetermined property. A property is undetermined until it triggers. ✓ is the example count and ✗ is the counterexample count; large counts are shortened, as in 186k. ID is the property ID, for `snouty runs property`.

Filter by status with --passing, --failing, and --undetermined. Give more than one to show each of those statuses.

Narrow with --name and/or --group. Both are case-insensitive substring matches against the relevant fields. Add --detail to expand the matches into their examples and counter-example moments instead of the table. To show one property by its ID, use `snouty runs property <run_id> <property_id>`.

Examples:
  snouty runs properties <run_id> --failing
  snouty runs properties <run_id> --failing --undetermined
  snouty runs properties <run_id> --name eventually_validate --detail
  snouty runs properties <run_id> --group Unreachable --detail

Add --json for machine-readable output. Each property prints as one JSON object on its own line. --json is mutually exclusive with --detail:
  snouty --json runs properties <run_id> --failing | jq -r .name
