# snouty mcp
#
# An MCP server on the stdio transport, gated behind the `mcp` unstable
# feature. tests/mcp.rs drives the server with an MCP client, and covers
# what a tool call returns. This spec covers the gate and the params.

# 1. With the feature off, snouty refuses the command, names the variable
#    that enables it, and points to its help.
! snouty mcp
stderr '`snouty mcp` is an unstable feature and is not enabled'
stderr 'enable it by setting SNOUTY_UNSTABLE_FEATURES=mcp'
stderr 'run `snouty mcp --help` for what it does'

# 2. An unknown id does not enable it.
env SNOUTY_UNSTABLE_FEATURES=runs-exec
! snouty mcp
stderr 'SNOUTY_UNSTABLE_FEATURES=mcp'

# 3. With the feature on, `settings show` lists it in its features row.
env SNOUTY_UNSTABLE_FEATURES=mcp
snouty settings show
stdout '^features\s+mcp$'

# 4. At least one tool call must be able to run.
! snouty mcp --max-concurrent-calls 0
stderr 'invalid value .0. for .--max-concurrent-calls'

# 5. A client that closes stdin before it sends a request stops the server,
#    which exits 0.
stdin empty.txt
snouty mcp
! stdout .

# 6. A command that prints the same in both forms has no `json` param, and
#    `detail` is never a param. A bad param fails before any command runs.
# Stdin closes as soon as the server reads calls.jsonl, and a call still
# running then can lose its response. So no call here may reach the API.
# The spec engine drops the final newline of a file, so the server never
# reads the last line of calls.jsonl, a ping.
stdin calls.jsonl
snouty mcp
stdout '"id":2,.*"text":"invalid params: unknown param: json"'
stdout '"id":3,.*"text":"invalid params: unknown param: detail"'

-- calls.jsonl --
{"jsonrpc":"2.0","id":1,"method":"initialize","params":{"protocolVersion":"2025-06-18","capabilities":{},"clientInfo":{"name":"spec","version":"1"}}}
{"jsonrpc":"2.0","method":"notifications/initialized"}
{"jsonrpc":"2.0","id":2,"method":"tools/call","params":{"name":"docs_show","arguments":{"path":"x","json":true}}}
{"jsonrpc":"2.0","id":3,"method":"tools/call","params":{"name":"runs_list","arguments":{"detail":true}}}
{"jsonrpc":"2.0","id":4,"method":"ping"}
-- empty.txt --
