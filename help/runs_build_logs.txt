Stream a run's build and setup logs: everything the platform did before the test started.

Each log line has a timestamp, a stream (stdout or stderr), and its text. The whole build is streamed, so expect thousands of lines on a real run. Read the stderr lines first when a launch failed.

Each line prints as `timestamp [stream] line`.{% if cli %} Grep the stream tag to narrow it.{% endif %}

The timestamp is in the local timezone, with its UTC offset. Timestamps inside the line text stay as the build tools wrote them.

Examples:
  {{ t("snouty runs build-logs <run_id>")? }}
{%- if cli %}
  {{ t("snouty runs build-logs <run_id> | grep '\\[stderr\\]'")? }}
  {{ t("snouty runs build-logs <run_id> | grep -i 'error\\|denied'")? }}
{%- endif %}

{% if cli %}
Add --json for machine-readable output. Each log line prints as one JSON object on its own line:

{% else %}
With {{ t("--json")? }}, each log line prints as one JSON object on its own line.
