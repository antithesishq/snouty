Show the usage hours of recent runs, newest first.

Columns: RUN ID, HOURS, STARTED, ENDED. STARTED and ENDED are the start and end of the billable usage of the run, in the local timezone.

With --rollup, each row is the total of one day, week, or month, in the local timezone. A week starts on Monday. Columns: DATE, RUNS, HOURS. DATE is the last day of the period. A period with no runs does not show. When --started-after or --started-before cuts a period, the total of that period includes only the runs inside the filter.

--started-after and --started-before filter on the time that the usage of a run started. --limit counts rows: runs, or periods with --rollup.

Examples:
  snouty runs usage
  snouty runs usage --rollup week -n 4
  snouty runs usage --rollup month --started-after 2026-01-01T00:00:00Z

Add --json for machine-readable output. Each row prints as one JSON object on its own line. A run has the fields run_id, hours, start_time, and end_time; the times are RFC 3339 in the local timezone. A period has the fields date, runs, and hours:
  snouty --json runs usage --rollup month | jq -r '"\(.date) \(.hours)"'
