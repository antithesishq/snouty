# snouty mcp
#
# Serve snouty's run, docs and doctor commands to AI agents over the Model
# Context Protocol (streamable HTTP, stateless, JSON responses; or stdio). The server
# runs in the foreground. The endpoint is http://HOST:PORT/mcp.
#
# Directives:
#
#   - `mcp-server <args>` starts snouty in the background and waits for
#     `Listening on ADDR`. It sets MCP_ADDR and MCP_PORT.
#   - `mcp-call <tool> [json]` initializes a session and calls the tool. stdout
#     gets the one text block of the result. A result with `isError` fails,
#     with the text on stdout. A JSON-RPC error fails with `error CODE: MSG` on
#     stderr, and an HTTP error with `HTTP STATUS`. With `-bg`, the call runs
#     in the background, and `mcp-disconnect` closes its connection.
#   - `mcp-rpc [-host H] [-path P] [-origin O] <method> [json]` sends one
#     JSON-RPC request and prints its `result`.
#   - `mcp-stop [-TERM|-INT|-HUP]` sends the signal and waits for the exit.
#     It fails when the exit status is not 0. Then stdout and stderr are the
#     server's output, so the request log can be read.
#   - `mcp-stdio FILE <args>` runs snouty with the lines of FILE on stdin.
#     When it has one response line for each request, it closes stdin and
#     waits for the exit. stdout and stderr are the server's output.
#   - `mock-blackhole-server [-docs] NAME` is an API server that never
#     answers. It writes the file NAME.hit when a request arrives, and
#     NAME.closed when the client closes the connection. With -docs, it is the
#     docs server. `wait-file PATH` waits for a file.
#
# A docs tool refreshes the docs database before it reads it, as the docs
# commands do without --offline. The refresh goes to an address where nothing
# listens, so it fails fast and the tools read the fixture database.
env ANTITHESIS_DOCS_URL=http://127.0.0.1:9

# --- Feature gate ---

# snouty mcp is an unstable feature. While it is off, the command is refused
# with the name of the feature, and top-level help does not list it.
! snouty mcp --stdio

stderr 'SNOUTY_UNSTABLE_FEATURES=mcp'
snouty --help
! stdout '^  mcp '

snouty --help
stdout '^  mcp +Serve snouty'

# --- Flags ---

# The command has --host, --port and --allowed-host.
snouty mcp --help
stdout '--host'
stdout '--port'
stdout '--allowed-host'

# Each flag value is parsed before the server starts.
! mcp-server mcp --port bogus
stderr 'invalid value'

# --host takes an IP address. A name is not resolved.
! mcp-server mcp --host localhost
stderr 'invalid value'

# --allowed-host takes a host with an optional port, with no user info.
! mcp-server mcp --allowed-host user@myhost.example
stderr 'invalid value'
! mcp-server mcp --allowed-host myhost.example:99999
stderr 'invalid value'

# --- Request checks ---

# The server refuses a request whose Host header is not the listen address.
# This stops DNS rebinding. A name that resolves to the listen address is
# refused too.
! mcp-rpc -host evil.example tools/list
stderr 'HTTP 403'
! mcp-rpc -host localhost:$MCP_PORT tools/list
stderr 'HTTP 403'

# The server refuses a request that has an Origin header, as a browser sends.
! mcp-rpc -origin http://evil.example tools/list
stderr 'HTTP 403'

# The endpoint is /mcp. Every other path is not found.
! mcp-rpc -path /other tools/list
stderr 'HTTP 404'
mcp-stop

# Each --allowed-host adds a Host header value that the server accepts. A
# value with no port matches any port.
mcp-server mcp --port 0 --allowed-host myhost.example
mcp-rpc -host myhost.example tools/list
stdout '"name":"runs_show"'
mcp-rpc -host myhost.example:$MCP_PORT tools/list
stdout '"name":"runs_show"'
! mcp-rpc -host other.example tools/list
stderr 'HTTP 403'
mcp-stop

# --- Param validation ---
