Search the documentation

Uses full-text search across the Antithesis documentation database. The database is updated before each search unless you pass {{ t("--offline")? }}.

Prints ranked matches (title and page path); pass a path to `{{ t("snouty docs show")? }}`. Use {{ t("--list")? }} to print only the paths.

By default the query is searched as literal text. Pass {{ t("--match")? }} to treat the query as a raw SQLite FTS5 expression instead, enabling operators like AND/OR/NOT/NEAR, "quoted phrases", `title:` column filters, and `prefix*`.

Examples:
  {{ t("snouty docs search fault injection")? }}
  {{ t("snouty docs search \"config image\"")? }}
  {{ t("snouty docs search moment.branch")? }}
  {{ t("snouty docs search sdk setup")? }}
  {{ t("snouty docs search --match 'sdk NOT java'")? }}
