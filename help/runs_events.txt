Search a run's events for one or more substrings (all must match).

{% if cli %}A term{% else %}Each item of {{ t("--match")? }}{% endif %} is matched against the text an event carries: log output, an assertion's message and source function, and a test-composer command.

{% include "fragments/event_output.txt" %}

Matching runs server-side through the events-search API, the same route `{{ t("snouty runs search")? }}` takes. Every term must match, case-insensitively. The result is a sample of the matching events in no fixed order, capped at {{ t("--limit")? }}. Read {% if cli %}`snouty runs search --help`{% else %}`tool_help {"tool": "runs_search"}`{% endif %} to learn how to read a sample and how the run's timelines relate the events.

{% if cli %}
For log output, the equivalent search is:
  snouty runs search <run_id> \
    'filter(ev => ["a", "b"].every(t =>
      (ev.output_text || "").toLowerCase().includes(t)))'
with each term in lower case. `snouty --verbose runs events ...` prints the exact query, which also matches assertion messages and test-composer commands.
{% endif %}

Examples:
  {{ t("snouty runs events <run_id> -m error")? }}
  {{ t("snouty runs events <run_id> -m error -m node-0 -n 100")? }}

{% if cli %}
Add --json for machine-readable output. Each event prints as one JSON object on its own line:
  {{ t("snouty --json runs events <run_id> -m error | jq -r .moment.vtime")? }}
{% else %}
With {{ t("--json")? }}, each event prints as one JSON object on its own line.
