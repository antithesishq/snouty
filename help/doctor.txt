Check environment configuration

Verifies that your environment is properly configured for Antithesis testing. Runs health checks — container runtime, docker compose, your credentials ({% if cli %}stored by `snouty login`, or {% endif %}set in the ANTITHESIS_* environment variables), and API connectivity. To see the settings that snouty resolved, run `{{ t("settings show")? }}`.

snouty prefers an API key (full API access); a username and password is deprecated auth, accepted only by {% if cli %}`snouty launch` and {% endif %}`{{ t("snouty debug")? }}`.

When credentials are configured, doctor also contacts the Antithesis API to report the API and tenant versions and confirm connectivity. Pass {{ t("--offline")? }} to skip that network call.

The command fails if any required check fails.{% if cli %} Pass --json for a machine-readable report (e.g. to gate CI).{% else %} The report is JSON.{% endif %}

Examples:
  {{ t("snouty doctor")? }}
{%- if cli %}
  {{ t("snouty doctor --json | jq .ok")? }}
{%- endif %}
  {{ t("snouty doctor --offline")? }}
