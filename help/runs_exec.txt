Execute a bash script in a run that is in progress, at a moment.

The run must be ready. It can be a test run or a debugging session. The exec command will wait until the run is ready before running the script.

The script executes on a fresh branch of the multiverse, so it does not interact with other work happening in the session, like fuzzing or other executing commands.

{{ t("input_hash")? }} and {{ t("vtime")? }} identify the moment to execute at, and the moment must be warm. A warm moment is a moment that is loaded into the run. Every moment generated in the run is warm: by fuzzing, and by an earlier `{{ t("runs exec")? }}`, so the end moment of one command is warm for the next. A moment from another run is cold. Use {{ t("--source-run-id")? }} to load a moment from a different run. Rewarming a moment can take minutes and depends on the magnitude of the vtime. {% if cli %}The `--timeout` flag{% else %}`timeout`{% endif %} does not apply to the time it takes to rewarm a moment. Find a moment with `{{ t("runs properties --detail")? }}`{% if cli %}, `{{ t("runs search")? }}`, or `runs events`{% else %} or `{{ t("runs search")? }}`{% endif %}.

The script executes on the host, or in the container that {{ t("--container")? }} names. The command needs tenant release 64.0 or newer; `{{ t("snouty doctor")? }}` reports the tenant release.

Without {{ t("--events")? }}, the script's stdout and stderr stream to snouty's stdout and stderr. With {{ t("--events")? }}, snouty prints every event of the timeline to stdout while the script executes, as `{{ t("runs logs")? }}` prints them: the script's output, the workload's logs and assertions, and Antithesis events. On exit, a trailer on stderr documents the branch's end moment, to chain a follow-up command from. A non-zero exit code, a timeout, or a truncated stream fails snouty with exit code 1.

{%~ if cli %}
Omit SCRIPT to read the script from stdin — a pipe, a redirect, or a heredoc.

{%~ endif %}
Examples:
  {{ t("snouty runs exec <run_id> <hash> <vtime> 'uname -a'")? }}
  {{ t("snouty runs exec <run_id> <hash> <vtime> --container <name> 'ps aux'")? }}
  {{ t("snouty runs exec <run_id> <hash> <vtime> --events 'sleep 5'")? }}
  {{ t("snouty runs exec <run_id> <hash> <vtime> --source-run-id <id> --timeout 5m 'ls'")? }}
{%- if cli %}
  {{ t("echo 'ps aux' | snouty runs exec <run_id> <hash> <vtime>")? }}
  {{ t("snouty runs exec <run_id> <hash> <vtime> < script.sh")? }}
{%- endif %}

  snouty --json runs exec <run_id> <hash> <vtime> 'ls' \
    | jq -r 'select(.output_text != null).output_text'
  {% endfilter %}
