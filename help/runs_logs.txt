Stream the logs of one timeline of a run, up to a moment.

A run is a multiverse: a tree of timelines that branch from each other. A timeline is one continuous simulated execution of the system, and vtime (virtual time) is its simulated clock. A moment is an instant on a timeline, identified by an input_hash and a vtime; the input_hash is a hash of every input Antithesis sent up to that moment. A branch is a timeline that splits off another timeline at a moment.

{{ t("input_hash")? }} and {{ t("vtime")? }} identify a moment in the multiverse. If {{ t("--begin-vtime")? }} is specified, logs will start from that point rather than the root moment. When {{ t("vtime")? }} is not specified, logs will end at the end of the branch corresponding to the {{ t("input_hash")? }}. If the run is in progress, the {{ t("input_hash")? }} branch may be extended at any time.

{% if cli %}{{ t("input_hash")? }} is often negative, such as `-123`; pass it as it is, with no `--` before it. {% endif %}Find a moment with `{{ t("runs properties --detail")? }}`, `{{ t("runs events")? }}`, `{{ t("runs search")? }}`, or the failure moment of an incomplete run in `{{ t("runs show")? }}`.

Each event has a moment, a source, and a payload: log output, an SDK assertion, a fault, a container lifecycle change, or a test composer command.

{% if cli %}
Output: a `moment INPUT_HASH` divider is emitted at the start of each branch. Each event under a divider renders on one line as `VTIME [source] payload`. With {{ t("--detail")? }}, no fields are truncated, and additional fields are included in indented lines after the event.
{% endif %}
