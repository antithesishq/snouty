Show one property of a run, in full: its name, ID, group, category, team, status, example totals, and sample moments{% if cli %}, as `snouty runs properties --detail` shows them{% else %}, as `{{ t("runs properties")? }}` returns each property{% endif %}.

{% if cli %}The property ID is in the ID column of `snouty runs properties`, in its --detail output, and in its JSON output.{% else %}{{ t("property_id")? }} is the id field of a property that `{{ t("runs properties")? }}` returns.{% endif %} Property lookup needs a run created on release 65.3 or later.

Examples:
{%- if cli %}
  {{ t("snouty --json runs properties <run_id> --failing | jq -r .id")? }}
{%- endif %}
  {{ t("snouty runs property <run_id> <property_id>")? }}

{% if cli %}
Add --json for machine-readable output. The property prints as one JSON object:
  {{ t("snouty --json runs property <run_id> <property_id> | jq .counterexample_count")? }}
{% else %}
With {{ t("--json")? }}, the property prints as one JSON object.
{% endif %}
