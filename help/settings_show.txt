Print the settings that snouty resolved

Prints each setting with the value that snouty resolved for it. For each setting, snouty uses the first value that it finds: the environment variable, the selected profile in the project settings file, the selected profile in the global settings file, the top-level value in the project settings file, then the top-level value in the global settings file.

Then it lists the settings files that snouty read, least to most specific, with where it found each one: `global`, `current directory`{% if cli %}, {{ t("--settings")? }} or SNOUTY_SETTINGS_PATH{% else %}, or a path in the server's settings{% endif %}. A value in a later file overrides the same value in an earlier one.

{% if cli %}Pass {{ t("--json")? }} to print one JSON object.{% else %}The result is one JSON object.{% endif %} `settings` holds each setting, with null for a setting that is not set and has no default. `files` lists the settings files in the same order, each with its `path` and `source`.

Examples:
  {{ t("snouty settings show")? }}
{%- if cli %}
  {{ t("snouty --profile staging settings show")? }}
  {{ t("snouty settings show --json | jq -r .settings.tenant")? }}
{%- endif %}
