# snouty mcp
#
# An MCP server on the stdio transport, gated behind the `mcp` unstable
# feature. tests/mcp.rs drives the server with an MCP client. This spec
# covers the gate, and what a tool call returns.

# 1. With the feature off, snouty refuses the command, names the variable
#    that enables it, and points to its help.
! snouty mcp
stderr '`snouty mcp` is an unstable feature and is not enabled'
stderr 'enable it by setting SNOUTY_UNSTABLE_FEATURES=mcp'
stderr 'run `snouty mcp --help` for what it does'

# 2. An unknown id does not enable it.
env SNOUTY_UNSTABLE_FEATURES=runs-exec
! snouty mcp
stderr 'SNOUTY_UNSTABLE_FEATURES=mcp'

# 3. With the feature on, `settings show` lists it in its features row.
env SNOUTY_UNSTABLE_FEATURES=mcp
snouty settings show
stdout '^features\s+mcp$'

# 4. At least one tool call must be able to run.
! snouty mcp --max-concurrent-calls 0
stderr 'invalid value .0. for .--max-concurrent-calls'

# 5. A client that closes stdin before it sends a request stops the server,
#    which exits 0.
stdin empty.txt
snouty mcp
! stdout .

# 6. A tool call returns what its command prints in the detailed text
#    form: `runs list` prints a block per run. With `json`, the call returns
#    what the command prints with --json: one JSON object per run.
# The spec engine drops the final newline of a file, so the server never
# reads the last line of calls.jsonl, a ping.
mock-runs-server
stdin calls.jsonl
snouty mcp
stdout '"id":2,"result":\{"content":\[\{"type":"text","text":"Run ID +[^ ]'
[!staging] stdout '"id":2,.*"text":"Run ID +run-1\\\\nStatus +completed\\\\nCreated +[^\\\\]+\\\\nLauncher +nightly\\\\nDescription +nightly smoke on main\\\\n'
stdout '"id":3,"result":\{"content":\[\{"type":"text","text":"\{\\\\"[a-z_]+\\\\":'
[!staging] stdout '"id":3,.*\\\\"run_id\\\\":\\\\"run-1\\\\",\\\\"status\\\\":\\\\"completed\\\\"\}\\\\n"\}\]'

! stdout '"id":3,.*Run ID'

# 7. A command that prints the same in both forms has no `json` param, and
#    `detail` is never a param.
stdout '"id":4,.*"text":"invalid params: unknown param: json"'
stdout '"id":5,.*"text":"invalid params: unknown param: detail"'
