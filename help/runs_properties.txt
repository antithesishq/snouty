List a run's property (assertion) results{% if cli %}, one table per group{% endif %}.

Each property has its ID, name, group, and status: passing, failing, or pending. A pending property has not triggered yet, or its results are still being processed after the run ended. Each property also counts its examples and its counterexamples.

{% if cli %}
Each table is headed by its group; columns are STATUS, ✓, ✗, ID, NAME (failing first). STATUS is pass, fail, or pending. ✓ is the example count and ✗ is the counterexample count; large counts are shortened, as in 186k. ID is the property ID.
{% else %}
Each property prints as a block: its Name, ID, Group, Category, Team and Status (passing, failing, or pending), then its sample moments. An event property has a table of moments with STATUS (failing or passing), HASH and VTIME columns, failing first. The table is a sample, and the Examples line above it gives the totals of the run. Pass a row's HASH and VTIME as the input_hash and vtime of `{{ t("runs logs")? }}`. A property with no events shows its values under Counter-examples, Examples or Result. Thus one call gives the moments of every property that matches, and you do not need a `{{ t("runs property")? }}` call for each one.
{% endif %}

Filter by status with {{ t("--passing")? }}, {{ t("--failing")? }}, and {{ t("--pending")? }}. Give more than one to show each of those statuses.

Narrow with {{ t("--name")? }} and/or {{ t("--group")? }}. Both are case-insensitive substring matches against the relevant fields.{% if cli %} Add --detail to expand the matches into their examples and counter-example moments instead of the table. Pass a moment to `{{ t("snouty runs logs <run_id> <input_hash> <vtime>")? }}` to read the logs leading up to it.{% endif %} To show one property in full, pass its ID to `{{ t("snouty runs property <run_id> <property_id>")? }}`.

Examples:
  {{ t("snouty runs properties <run_id> --failing")? }}
  {{ t("snouty runs properties <run_id> --failing --pending")? }}
  {{ t("snouty runs properties <run_id> --name eventually_validate --detail")? }}
  {{ t("snouty runs properties <run_id> --group Unreachable --detail")? }}

With {{ t("--json")? }}, each property prints as one JSON object on its own line, with its samples in `examples` and `counterexamples`. An empty array is left out. An event sample gives its moment as `moment.input_hash` and `moment.vtime`.
