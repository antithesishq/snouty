Give Docker or Podman the credential for the tenant's container registry

A Docker credential helper for the tenant registry, registry.<tenant>.antithesis.com. Docker and Podman run docker-credential-snouty, an alias of snouty: when snouty starts by that name, it runs the helper. The shell script installer and the Nix package make the alias as a symlink next to snouty. For another install method, make the symlink in a directory on your PATH, for example:

  ln -s "$(command -v snouty)" ~/.local/bin/docker-credential-snouty

To use the helper, add the registry to "credHelpers" in ~/.docker/config.json for Docker, or in ~/.config/containers/auth.json for Podman:

  {
    "credHelpers": {
      "registry.<tenant>.antithesis.com": "snouty"
    }
  }

The helper uses the same settings as snouty in the directory where Docker runs it, including ./.snouty.toml. With {{ t("--profile")? }}, ANTITHESIS_PROFILE, {{ t("--settings")? }} or SNOUTY_SETTINGS_PATH, the helper uses only those settings. Otherwise it uses the first profile whose repository is on registry.<tenant>.antithesis.com.

Then `docker push`, `docker pull`, `podman push` and `podman pull` automatically use your snouty credentials for the Antithesis docker registry.

The registry requires tenant version 66 or later; `{{ t("snouty doctor")? }}` reports your tenant version.

Use this command to debug the helper or specify {{ t("--profile")? }} and {{ t("--settings")? }} in a wrapper script.

Examples:
  echo registry.acme.antithesis.com | snouty docker-credential get
