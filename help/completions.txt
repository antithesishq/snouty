Output shell completions

Writes a completion script for SHELL to stdout.

Have your shell run this command at startup rather than saving its output to a file. A saved script describes the snouty that wrote it, and goes stale when `snouty update` installs a new version. If your shell already initializes completion, add only the snouty line after that initialization. Open a new shell to load the setup, and again after each update.

For zsh, add this to ~/.zshrc:
  autoload -Uz compinit
  compinit
  source <(snouty completions zsh)

For bash, add this to ~/.bashrc:
  source <(snouty completions bash)

For fish, put this line in ~/.config/fish/completions/snouty.fish:
  snouty completions fish | source

For elvish, add this to ~/.config/elvish/rc.elv:
  eval (snouty completions elvish | slurp)

For PowerShell, add this to $PROFILE:
  snouty completions powershell | Out-String | Invoke-Expression
